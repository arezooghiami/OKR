## ۱. اصول ناوبری

- **ناوبری کناری راست (RTL)** با رجیستری منو؛ هر آیتم فقط برای کسی که دسترسی «مشاهده» دارد دیده می‌شود.
- **انتخابگر چرخه** سراسری در سربرگ؛ همه صفحات در بستر چرخه انتخاب‌شده کار می‌کنند (پیش‌فرض: چرخه جاری).
- **جستجوی سراسری** (Ctrl+K): واحد، Objective، KR، کاربر.
- **هر صفحه خانه مرتبط با نقش** دارد؛ کاربر با چند نقش، نقش فعال را عوض می‌کند.
- هر عدد درصدی قابل کلیک تا فرمول و داده منبع است.

## ۴. جریان‌های کلیدی

### F1 — ثبت مقدار دور مرور (هدف: حداکثر ۳ کلیک)
1. خانه «KRهای من» ← کلیک روی KR دارای نشان «ثبت‌نشده» (کلیک ۱).
2. ورود مقدار در ردیف درجا؛ درصد و وضعیت **لحظه‌ای** نمایش داده می‌شود؛ یادداشت اختیاری (کلیک ۲).
3. پیش‌نویس خودکار ذخیره می‌شود؛ «ارسال برای تأیید» (کلیک ۳) — تکی یا دسته‌ای.
- **حالت‌ها:** دور قفل‌شده (فقط‌خواندنی با دلیل)، مقدار خارج از بازه (هشدار نه خطا)، قطع شبکه داخلی (پیش‌نویس محلی + پیام)، مقدار خالی ≠ صفر.

### F2 — تأیید دور توسط مدیر واحد
صف تأیید ← مرتب‌سازی بر اساس عقب‌ترین ← مشاهده مقدار قبل/بعد و یادداشت ← تأیید / برگرداندن با دلیل ← تأیید دسته‌ای ← قفل دور برای آن واحد.

### F3 — راه‌اندازی چرخه جدید (هماهنگ‌کننده)
`/cycles` ← «چرخه جدید» ← نام و بازه جلالی ← (اختیاری) کپی از چرخه قبل بدون مقدار ← تعریف دورها و تاریخ‌ها ← بازبینی snapshot ساختار ← فعال‌سازی ← یادآوری به مدیران واحد.

### F4 — تعریف Objective و KR (مدیر واحد)
واحد ← «Objective جدید» ← عنوان/توضیح/مالک/وزن ← افزودن KR (نوع، مبنا، هدف، واحد اندازه‌گیری، مسئول، هدف کلان، شرح انتظار) ← پیش‌نمایش محاسبه ← ذخیره. شماره‌گذاری خودکار.

### F5 — همترازی و تعهد بین‌تیمی
Objective ← «اتصال به هدف بالاتر» (جستجو در همه واحدها، جلوگیری از حلقه) · یا «درخواست از واحد دیگر» ← متن/مهلت/KR اختیاری ← واحد مقصد: پذیرش / رد با دلیل ← انجام ← نمایش در داشبورد تعهدات.

### F6 — ایمپورت داده (هماهنگ‌کننده/IT)
انتخاب نوع قالب ← دانلود قالب نسخه‌دار ← آپلود ← **گزارش اعتبارسنجی ردیفی** (خطا/هشدار با شماره ردیف) ← پیش‌نمایش dry‑run (چه چیزی ساخته/تغییر می‌کند) ← تأیید ← اعمال تراکنشی ← لاگ ایمپورت.

### F7 — تغییر ساختار سازمانی وسط چرخه
`/admin/org` ← ویرایش درخت (جابجایی/ادغام/ایجاد) ← پیش‌نمایش اثر روی گزارش‌ها ← «اعمال از تاریخ …» ← نسخه جدید snapshot ← گزارش‌های قبل ساختار قدیم را حفظ می‌کنند.

### F8 — تنظیم و آزمایش دسترسی
`/admin/roles` ← انتخاب/کپی نقش ← ماتریس (عمل × منبع × محدوده × اثر) ← ذخیره ← `/admin/access-simulator`: کاربر + عمل + منبع ← نتیجه «مجاز/ممنوع» + **قانون مؤثر و دلیل**. هر تغییر در Audit ثبت می‌شود.

### F9 — گزارش پایان دور
`/reports` ← انتخاب چرخه/دور/قالب ← پیش‌نمایش ← PDF یا Excel (فونت محلی، RTL).

## ۵. حالت‌های سراسری (باید برای هر صفحه طراحی شود)

خالی (با اقدام بعدی پیشنهادی) · در حال بارگذاری (اسکلت، نه چرخان) · خطا (قابل تلاش مجدد) · بدون دسترسی · فقط‌خواندنی (چرخه بسته/دور قفل) · ذخیره‌نشده (هشدار خروج) · دمو (نوار مشخص بالای صفحه).
