# سیستم طراحی OKR

نسخهٔ ۳، پالت A «کنیاک و عاج» (فاز ۱ نقشهٔ راه، آبان ۱۴۰۵). این سند همان چیزی را می‌گوید که در کد پیاده شده است.
مرجع تصمیم: [07-review-and-roadmap.md](../07-review-and-roadmap.md) بخش ۳. طرح‌های قدیمی در [archive/](archive/) بایگانی‌اند.

## هدف‌ها
هر تصمیم طراحی باید یکی از این سه هدف را جلو ببرد:
- **ثبت پیشرفت راحت‌تر از اکسل**
- **گزارش قابل اعتماد برای مدیریت**
- **پایش سریع و دقیق** برای مدیر واحد و مدیر سامانه

صفحه‌ها برای ساعت‌ها کار روزانه طراحی می‌شوند: آرام، خوانا و بدون رنگ اضافه.

## ساختار CSS
چهار فایل در `frontend/src/styles/`. ترتیب لایه‌ها در `tokens.css` اعلام شده است: `@layer tokens, base, components, screens`.

| فایل | محتوا |
|---|---|
| `tokens.css` | همهٔ متغیرها: رنگ روشن و تیره، مقیاس فونت، وزن‌ها، شعاع‌ها |
| `base.css` | فونت، ریست، پیش‌فرض‌های سند، ابزارهای کوچک (`.num`، `.mut`، `.ok`…) |
| `components.css` | پوسته و منو، دکمه، فیلد، برچسب، کارت، KPI، فهرست، جدول داده، پنل کناری، تقویم جلالی، صفحهٔ ورود |
| `screens.css` | چیدمان مخصوص هر صفحه و قواعد ریسپانسیو |

هیچ رنگ hex در کامپوننت‌های tsx نیست. فقط `var(--…)` به کار می‌رود.

## قواعد رنگ
- **تأکید کمتر از ۳٪ صفحه.** فقط این‌جاها: دکمهٔ اصلی، لینک، حلقهٔ فوکوس و نشانگر «اینجا هستید». نشانگر یک نوار ۳px به رنگ تأکید است: آیتم فعال منو، مرحلهٔ جاری، جلسهٔ بعدی، سطر انتخاب‌شده، کارت «منتظر ثبت» و قدم بعدی راه‌اندازی.
- **رنگ فقط یعنی وضعیت.** برچسب هدف کلان خنثی است و فقط نقطهٔ رنگی دارد. شمارهٔ هدف، «+ افزودن» و کادر KPIها خنثی‌اند. ماتریس داشبورد با رنگ وضعیت رنگ می‌خورد، نه با رنگ تأکید.
- **وضعیت هرگز فقط رنگ نیست**: پای، درصد و کلمه (`.badge`) با هم می‌آیند.
- همهٔ متن‌ها در روشن و تیره کنتراست ≥ ۴٫۵:۱ دارند. این را ممیزی خودکار فاز ۱ روی ۱۳ صفحه بررسی کرد.

## تایپوگرافی
- فونت Vazirmatn محلی، ارقام فارسی، و `tabular-nums` برای عدد.
- **هفت اندازه:** ۱۳ / ۱۴ / ۱۵ / ۱۷ / ۲۰ / ۲۴ / ۳۲px (`--fs-xs` تا `--fs-3xl`). بدنه ۱۵px است و هیچ متنی زیر ۱۳px نیست.
- **سه وزن:** ۴۰۰ / ۵۰۰ / ۶۰۰. وزن ۷۰۰ فقط برای عنوان صفحه و عدد KPI است.
- سرستون‌ها و برچسب‌ها ۵۰۰ هستند، نه پررنگ.
- **جداکننده:** کنار عدد فارسی «·» نگذارید، چون شبیه صفر خوانده می‌شود. به جایش «،» یا «؛» بگذارید.

## شکل و فاصله
- **چهار شعاع:** ۴ / ۸ / ۱۲ / کپسولی (`--r-sm`، `--r-md`، `--r-lg`، `--r-pill`).
- فاصله‌ها روی گام ۴px هستند.
- کارت‌ها سایه ندارند. فقط لایه‌های شناور سایه دارند: منو، پنل کناری، تقویم و پالت فرمان.
- ارتفاع سطر و هدف لمسی حداقل ۴۴px است (`--row-min`).
- حداکثر عرض محتوا ۱۱۸۰px است.

## جدول‌ها
- **یک قاب واحد.** خط ستون و سطر دارد، **بدون راه‌راه**.
- سرستون چسبان است و زمینهٔ `--surface-2` دارد.
- سرگروه هدف نوار `--band` است.
- سطر فعال = نوار ۳px تأکید + زمینهٔ `--selected`.
- خانهٔ خالی «—» کم‌رنگ است.
- کنترل‌ها تا هاور یا فوکوس آرام‌اند.

پیاده‌سازی‌ها:
- `.sheet` + `.ob/.og/.kh/.kr2`: صفحهٔ جلسه
- `table.xl`: جدول واحد
- `.list` + `.row`: فهرست واحدهای داشبورد
- `table.dt` در `.tw`: جدول داده (همهٔ پایش‌ها، ورود از اکسل، پرونده)

## کامپوننت‌ها
- **منوی کناری روشن** سمت راست است:
  - علامت محصول، «OKR» و نام دوره بالای منو می‌آید.
  - امضای «A.G» پایین منو است.
  - روی موبایل نوار پایین می‌شود، با برچسب‌های تک‌کلمه‌ای (`short`).
- **نوار بالا:** جستجو (Ctrl+K)، تم، و منوی حساب (خروج، نسخه، A.G).
- **دکمه:** اصلی (`.btn`، تنها جای پررنگ تأکید)، فرعی (`.btn.o`)، کوچک (`.mini`) و خطر (`.danger`).
- **فیلد:** ارتفاع ۴۰px. فوکوس = کادر تأکید + حلقهٔ `--accent-soft`.
- **کنترل تب‌مانند (`.seg`)**، **نوار مراحل (`.steps`)**، **پنل کناری (`.peek`)** (روی موبایل از پایین باز می‌شود).
- **KPI:** کادر خنثی، عدد ۳۲px/۷۰۰. روی موبایل یک ستون است.
- **حالت خالی (`Empty`):** آیکن، عنوان، و این‌که چه کسی می‌تواند وضعیت را عوض کند.
- **صفحهٔ ورود:** علامت محصول، جملهٔ ارزش، فرم و امضای A.G.
